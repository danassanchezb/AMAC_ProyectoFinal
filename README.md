**Paleta de colores**

Utilizamos estos colores para el diseño de la página

- --color-primario, #202945 -> Azul marino principal
- --color-fondo, #FFFFFF -> Fondo blanco
- --color-secundario, #CAE4EF -> Azul claro
- --color-acento, #FF815C -> Naranja para botones y elementos destacados


**Tipografías**

- Baskervville: títulos y encabezados
- Work Sans: textos, botones, formularios y navegación


**Componentes reutilizables**

- Encabezado: incluye el logotipo de AMAC y los elementos de navegación
- Barra de navegación: permite acceder a diferentes secciones de la plataforma
- Botones: mantiene estilos consistentes para acciones como iniciar sesión, registrarse y postularse
- Tarjetas de vacantes: muestran información de los empleos disponibles
- Formularios: se usan para el registro e inicio de sesión de candidatos y empresas
- Pie de página: información de AMAC
- Iconos SVG: se reutilizan en menús, botones y secciones informativas
  Los estilos generales se estan en base.css, layout.css y componentes.css y
  los estilos específicos están organizados en archivos CSS por aparte


**Diseño responsivo**

Para hacer nuestro proyecto responsivo utilizamos CSS y media queries para adaptar 
la distribución de la página a diferentes tamaños de pantalla, primero desarrollamos 
la vista de teléfono y luego adaptamos con css para computadora.
